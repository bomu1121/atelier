# Atelier · 画室

个人绘画学习的**多方案实验场**。名字取自 19 世纪学院派的师徒制画室（atelier）：一个屋里多位导师、大量练习与指导记录并存——**没有唯一正统**。

## 这个库存什么

| 目录 | 内容 |
| --- | --- |
| `NN-模型或表述/` | 一份完整的绘画指导方案（不同 AI 模型 / 不同表述方式各生成一份，平权并存，供对比） |
| `qa/` | 针对细节的请教记录（方案是大纲粒度，细节靠一次次问答沉淀） |
| `practice/` | 练习存档（按 `年-月/日期-主题` 归档，如果开始画了再说） |

## 核心约定

1. **方案平权**：任何一份方案（包括 01）都不指导整个项目。它们是候选，不是宪法。新方案进来只加序号，不覆盖旧的。
2. **请教记录独立于方案**：`qa/` 里的记录标注「当时请教的是哪个方案」，但结论归整库所有——问答里沉淀的细节，价值往往高于大纲本身。
3. **每个方案目录必须带元信息头**：来源模型、生成日期、原始需求、已知局限。没有元信息的方案不可信。

## 请教记录怎么归档

- 文件名：`qa/YYYY-MM-DD-主题.md`，一天多次同主题就加序号。
- 新建时从 [qa/TEMPLATE.md](./qa/TEMPLATE.md) 复制头部的元信息块。
- 一次请教解决一个主题；跨主题拆多个文件，方便日后按主题检索。

## 用阅读器看文档（推荐）

**日常**：双击桌面快捷方式「atelier reader」→ 自动启动服务器并打开浏览器（控制台窗口最小化在任务栏，关它即停服务）。

**命令行 / 换新机器**：

```bash
node reader/server.mjs     # Node ≥ 20，无需 npm install；默认 http://127.0.0.1:8765
```

换机器要重建桌面快捷方式时：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/create-shortcut.ps1`（脚本纯 ASCII，路径运行时推导，中文用户名/桌面重定向都兼容）。

功能：侧边栏全库文件树 + 「最近更新」（git 历史驱动）、GFM 表格渲染、正文内 `.md` 链接直接跳转（如 `./RESOURCES.md`）、每页自动生成右侧目录、迭代日志自动时间线视图、亮/暗主题（记忆选择）。**完全离线**（marked 已 vendored 在 `reader/vendor/`），不联网可用。端口被占会自动 +1 重试，也可 `PORT=9000 node reader/server.mjs` 指定。

```
├── qa/

```
