# M07 · 数位板排障清单

> **一句话**：压感「忽然没了」九成是**驱动 / 系统服务 / 软件设置**问题，不是板子坏了——按固定顺序排查，别乱重装。
> **适用**：01-glm 阶段 0（装好后跑一遍预检）+ 全程救火。
> ⚠️ **本模块未逐条实测**（写作者没有完整硬件环境可复现全流程）：排查顺序是 Wacom 官方支持框架 + 社区通识的整理，菜单名以你驱动实际版本为准。

## 一、先分类：你是哪种症状

| 症状 | 大概率是 | 去哪节 |
| --- | --- | --- |
| 完全没压感（线条粗细不变） | 驱动服务 / 接口模式 | §二 |
| 昨天还好，今天没了 | 服务崩溃 / 系统更新踩坏配置 | §二 |
| 线条延迟、跟不上笔 | 稳定器 / 接口模式 / 性能 | §三 |
| 光标偏移（笔尖与光标不重合） | 映射失准（多显示器高发） | §四 |
| 不能悬停 / 悬停乱飘 | 感应高度设置 | §五 |
| 笔侧键在某个软件失灵 | 应用专属配置 | §五 |

## 二、没压感：固定排查顺序（最常见，按顺序别跳）

1. **换软件测**（30 秒）：换另一个绘画软件，或用驱动自带的「测试画笔」功能。
   - 别的软件有压感 → **问题在这个软件的设置**（§六 对照开关）。
   - 全都没有 → 继续往下。
2. **查系统服务**（2 分钟）：`services.msc` 里找厂商服务。Wacom 体系常见的有：`TabletServicePen`、`Tablet PC Input Service`、`Wacom Professional Service`（驱动版本不同名字略有差异）。
   - **要求：状态「正在运行」+ 启动类型「自动」**。被停用或被安全软件拦截 → 改回来再测。
3. **重启驱动**（1 分钟）：Wacom Center / 桌面中心 → 设置 → **重启驱动程序**（比重启电脑快得多）。系统更新后失效的，多数在这一步回来。
4. **切换 Windows Ink / WinTab**（2 分钟）：驱动设置里找「启用 Windows Ink」开关，**切换一次再测**。
   - 这是 Win10/11 下压感失灵的**头号高发原因**：Windows Ink 与 WinTab 接口冲突时压感直接中断。
   - Windows Ink 的压力级别较低（约 1024 级），WinTab 更高、按键支持更完整——**非屏板子优先试 WinTab**。
5. **重装驱动**（约 10 分钟）：只从**品牌官网**下载对应「型号 + 系统版本」的最新驱动。顺序：卸载旧驱动 →（Wacom 有官方 Clean Driver Utility 清残留）→ 安装新驱动 → 重启。
6. **硬件排除**（最后做）：换数据线、换 USB 口（**直插主板口**，避开 hub / 延长线）；无线笔换电池或充电；换新笔尖。全换完还不行，才怀疑板子或笔。

## 三、延迟 / 滞后

- **先降软件稳定器**：稳定器档位越高越滞后——这是它的工作原理（平滑度和跟手性是此消彼长，见 [M02](./M02-canvas-and-pressure.md) §四）。
- **切 WinTab**（若当前是 Windows Ink）：多数情况下延迟更低。
- 画布别开过大（[M02](./M02-canvas-and-pressure.md) §一）；低配设备画图时关掉多余后台（浏览器多标签是大头）。
- 蓝牙笔对延迟敏感：支持有线就优先有线。

## 四、光标偏移

1. **重新映射**：驱动里把「映射到屏幕」重设一遍；多显示器**先确认映射到了哪块屏**（映射错屏 = 完全对不上）。
2. **比例对齐**：板子有效区与屏幕长宽比不一致 → 圆画成椭圆（自检方法见 [M02](./M02-canvas-and-pressure.md) §五）。
3. 非屏板子的**轻微**偏移是结构性的（板面与屏幕视角不同导致物理视差），无法完全消除——养成「用板子中间区域、少触边缘」的习惯即可。

## 五、悬停与按键

- **悬停乱飘**（光标自己动）：把驱动里的**感应高度 / 悬停距离调低**。
- **悬停不灵**（必须贴住板子光标才动）：调高感应高度。
- **笔不碰板就在画**：笔尖开关粘连或脏了——清洁，不行换笔尖组件。
- **侧键只在个别软件失灵**：多半是「应用专属配置」没建——多数驱动支持为每个软件存一套按键映射，给你的绘画软件单独建一份。
- 小习惯：**不用笔时别把笔搁在板子上**，会持续触发光标。

## 六、各绘画软件的压感开关（快速对照）

| 软件 | 检查项 |
| --- | --- |
| Photoshop | 画笔 → 形状动态 → 控制 = 「钢笔压力」（旁边不应有黄色感叹号） |
| SAI 2 | 其他设定 → 笔压设定：最小笔压设为 0、勾选启用笔压 |
| Krita | 设置 → 配置 Krita → 输入设备：确认设备为「已启用」 |
| CSP | 文件 → 环境设置 → 平板/数位板：确认接口模式 |

（位置来自 2026-10-10 网络资料整理（【搜索】），菜单名随版本会移动。）

## 七、红线与收尾

1. **排查顺序：软件 → 配置 → 驱动 → 线材 → 硬件**。倒着来（先怀疑板子）最浪费时间。
2. **不装第三方「驱动大师」类工具**；驱动只从官网拿。
3. **不为压感重装系统**——它排在整个链条的最后面。
4. **修好之后**：把「哪一步救回来的」写进 `practice/年-月/log.md`——下次同类问题 30 秒定位。
