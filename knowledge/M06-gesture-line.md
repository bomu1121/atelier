# M06 · 动态线：重心与趋势

> **一句话**：一张人体速写的生死线只有一条——从**承重脚**穿过躯干延伸到头顶的「动作主曲线」。动态线画不好的根因通常是**看不出来**，所以本模块一半篇幅在教「看势」。
> **适用**：01-glm 每日速写热身（阶段 1~3 全程）、阶段 3 人体主课。

## 一、动态线是什么（和它不是什么）

**是什么**：贯穿全身的一条主曲线，表达身体在空间中的**流向**。三种基本形，动态强度递增：

| 形 | 特征 | 例子 |
| --- | --- | --- |
| **I 形** | 基本直立，几乎无弯曲 | 立正、笔直站立 |
| **C 形** | 一侧压缩、整体偏向另一侧 | 叉腰站姿（对立式平衡）、持物前倾 |
| **S 形** | 两个反向的弯，动态最强 | 跑步、跳舞、躺姿扭转 |

**不是什么**（新手三大误解）：

1. **不是外轮廓**。轮廓是「墙」，动态线是「骨架的势」。照着轮廓描边 = 画出一具僵硬的壳。
2. **不是中轴线**。不是把人从正中间劈开的竖线——它**随重心的流向弯曲**，常常完全偏离中线。
3. **不是随便一条曲线**。它必须**经过承重脚**——没有承重的曲线只是装饰。

## 二、读图三步法（每张照片 5 秒，落笔之前）

1. **找承重**（2 秒）：哪只脚（或哪侧臀部、手肘）压着支撑面？
2. **从承重侧走主线**（2 秒）：承重脚 → 胯 → 胸腔 → 头，在心里走一遍，判断它是 I / C / S。
3. **看趋势与转体**（1 秒）：头顶与承重脚的连线往哪边倾 = 动作趋势；肩线与胯线是否**平行**——不平行 = 有转体（胸腔和骨盆朝向不同，速写里是最容易丢的信息）。

**读图先于落笔是硬纪律**：30 秒的速写里读图占 5 秒，回报是把「撞大运」变成「有意识」。（会话结构见 [M03](./M03-timed-sketch.md)。）

## 三、一笔的质地：主线的画法

- **起笔在承重脚**，一笔画到头顶（或从头顶一笔画下来——选一条路线，中途不断笔）。**断笔 = 势断**。
- **一条线只拐一次弯**：C 形拐一次、S 形拐两次。出现三个以上的弯或反复来回——那是犹豫，不是动态。
- **主线用力最重、最长、最连贯**；四肢是它的「旁注」，画得轻、快、短。视觉上主线要**压得住**其它所有线。
- **弯曲要夸张**：照片里 5° 的倾角，画的时候可以放大到 15°——速写是提炼不是复印。（注意：这和「定点-比例」临摹的精准模式是两套练法，别混用。临摹练准，速写练势。）
- **手臂悬空画**：主线常超过 15cm，手腕画不出来（发力机制见 [M01](./M01-pen-control.md)）。

## 四、识势练习：先学会看，再学画（新手捷径）

画不出来往往是因为**看不出来**。识别训练比重复画更有效：

- **方法**：找古典人体速写（大师素描），在顶层用 2~3 笔把主描出来——**只描动态线，不描任何细节**。
- **素材**：大都会博物馆 Open Access 里的 figure study 类古典素描（CC0，筛选与下载方法见 [M05](./M05-practice-material.md)）——古典大师速写的动态线清晰、夸张，是识势的最好教材。
- **量**：每晚 5 张，连续 2 周（共 50 张）。之后看照片会自发「看见」那条线。

**判读自查**（每 20 张速写做一次）：遮住原照片只看你的速写，3 秒内能否指出（1）承重脚在哪（2）整体往哪倾。答不出就是动态线没画出来。

## 五、与「体块」共存（60 秒以上档位）

- **顺序**：动态线永远第一，体块是「挂」在主线上的——不是先摆方块再连线。
- **60 秒档**：主线 → 胸腔、骨盆两个方块**沿主线的方向**摆 → 四肢。别贪第三个方块（腿），来不及。
- **致命退化**：画完主线就忘了它，跑去抠手脚——主线已断，抠得再准也白搭。

## 六、常见错误与修正

| 症状 | 病因 | 修正 |
| --- | --- | --- |
| 僵硬、像纸片人 | 在描轮廓，没画势 | 回第四节识势练习；落笔前先读图 |
| 人「站不住」、发飘 | 主线没经过承重脚 | 起笔改在承重脚 |
| 线条反复来回、毛糙 | 不敢定形 | 一条线只拐一次；宁可拐错也不来回 |
| 每张都是 I 形 | 素材全是站姿 | 掺舞蹈/运动照片（见 [M03](./M03-timed-sketch.md) §六） |
| 四肢与主线打架 | 四肢画得太「满」 | 每肢 1~2 笔，总视觉权重不超过主线 |
| 转体丢了（平得像照片翻面） | 没看肩胯是否平行 | 读图第三步加进固定动作 |

## 来源与边界

- I/C/S 三分、承重侧起笔、「先看势再画势」：Proko、Vilppu、Mattesi《Force》等公开教学体系的通识（【共识】），社区长期实践。
- 「识势：每晚 5 张 × 2 周」「5 秒读图」「一条线只拐一次」：**本库编排，未实测**——按「识别训练先行」原则设计的量，不是验证过的最优值。
- 未覆盖：动物速写的动态线（原理相通，如需要另开模块）。
