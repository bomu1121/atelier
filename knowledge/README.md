# 知识模块（Knowledge Modules）

> **计划无关的小知识模块**：每个文件讲透一个具体问题，服务于实际练习。任何方案（01-glm 及后续所有方案）都引用这里，不重复造轮子——方案会换（不同模型、不同表述），但这些知识点是公共地基。

## 模块标准（写的和读的都按这个来）

每个模块必须包含四件：

1. **具体数字/档位** —— 可直接照做的参数，不写"适量""适当"
2. **为什么** —— 原理说清楚，不是只给结论（知道为什么，才能自己判断变体）
3. **自查/自测方法** —— 怎么知道自己做对了
4. **来源与边界** —— 哪些是社区共识、哪些是本库编排、哪些未经实测
