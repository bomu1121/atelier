# M04 · 叠图对比：把「感觉不像」变成可测量的偏差

> **一句话**：叠图是把"画得像不像"这个模糊问题**变成物理量（错位）**的唯一低成本手段——对比记忆靠不住，"我明明画对了"在叠图面前全部现形。
> **适用**：01-glm 每周临摹、出师考核第 3 项。

## 一、为什么必须叠

眼睛对**整体偏差**很不敏感，却会被**局部细节**带走注意力：你盯着画了十分钟的袖口线条觉得"挺像"，把两张图叠起来才发现整个肩颈低了 5 毫米——这是人的视觉系统的通病，不是态度问题。叠图强行把两张图放在同一坐标系里，偏差立即变成"错位的形状"，无处可藏。

## 二、数字做法（推荐，五步）

以 Krita / Procreate / CSP / SAI 任意一款为例（操作名略有差异）：

1. **底层放参考图**，不透明度降到 **40%~60%**。
2. **上层画临摹线稿**（你自己的画），不透明度 100%。
3. **闪切对比**：快速反复开关上层的可见性（或按住快捷键）。**会"动"的就是偏差处**——这是找偏差最快的方法，比盯着看准得多。
4. **进阶量化（可选）**：把参考层设为「差值 / Difference」混合模式——偏差越大的区域越亮，能一眼看出"哪里错得最大"。（差值模式对照片层不太行，线稿对线稿效果最好。）
5. **标记修正**：圈出错得最大的 **3 处**，每处写一句话原因：比例没测 / 角度错 / 曲线画得太直。写完原因，这次对比才算完成。

**注意**：叠图是**检查**动作，不能替代"定点-比例"的画法（阶段手册练习 7）。正确的流程永远是：先按方法画 → 再叠图检查 → 标原因 → 下一张改。**边叠边描 = 描红，不算练习。**

## 三、纸上做法

- **首选**：透写台（或提高亮度垫在窗玻璃上），把两层纸对齐透光看。
- **没设备**：手机拍照 → 传到数字软件里按数字做法处理（拍照时尽量正对、光匀）。
- 关键同样是「闪切找偏差 + 标 3 处原因」，设备不重要。

## 四、软件里的对应功能速查

| 软件 | 功能 | 用途 |
| --- | --- | --- |
| Procreate | 参考图层（Reference Layer） | 把参考锁定为对照层 |
| Krita | 洋葱皮（Onion Skin） | 多帧/多图对齐显示 |
| CSP | 参考窗口 / 洋葱皮 | 同上 |
| 通用 | 50% 半透明 + 闪切 | 万金油，哪都行 |

（功能名称按各软件官方文档的通用叫法整理，**未逐一实开验证**。）

## 五、频率与横向对比

- **每张临摹**：叠一次，标 3 处 + 原因，写进 `practice/年-月/log.md`。
- **每周一次横向对比**：把「本周第一张」和「最后一张」**同题材**并排（不是叠，是并排）。单张纵向叠图看"准不准"，每周横向对比看"进步趋势"——后者才是坚持的燃料。
- **每月一次与历史比**：和第 1 周的同题材放一起（对应出师考核第 5 项）。

## 六、常见错误

| 症状 | 病因 | 修正 |
| --- | --- | --- |
| 叠完只"哦"一声就翻篇 | 没落笔修正 | 修正动作（标 3 处+原因）才算完成对比 |
| 每次叠都错在同一个地方 | 没把原因带进下一张 | 打开上一张的 log，先读原因再动笔 |
| 越叠越依赖，离开参考就画不了 | 叠图代替了"测比例" | 回练习 7 的锚点流程；叠图只当考试，不当拐杖 |
| 差值模式一片亮 | 拿照片和线稿比 | 差值对线稿比较有效；照片层用闪切法 |

## 来源与边界

- 闪切对比、差值模式找偏差：绘画社区通用技巧（【共识】）。
- 「标 3 处 + 写原因」「每周横向对比」：**本库编排**；3 这个数量是按"一次改得动三件事"定的，未实测。
- 软件功能名称：通用叫法整理（【搜索】二级信息），未逐软件实测操作路径。
