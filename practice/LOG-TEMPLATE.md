# 每日练习日志模板

> 用法：当月第一次练习时，从本模板复制出 `practice/年-月/log.md`，之后每天收笔前追加 3 行。不超过 1 分钟。

```text
- MM-DD｜练了：〈热身参数 + 专项内容 + 自由画〉
- 最差：〈今天最差的一张：哪个练习、差在哪（一句话）〉
- 明天：〈明天下笔前要改的一件事（一句话）〉
```

填好的样子（照格式，别照内容）：

```text
- 10-14｜练了：排线W2参数 + 椭圆表1页 + 30s速写26张 + 自由画30min
- 最差：60s张四肢线全描碎，动力线没起完就抠手
- 明天：60s张只画5条线，主线一笔完成前不画任何别的
```

## 三行各自的用途

| 行 | 用途 | 相关模块 |
| --- | --- | --- |
| 练了 | 记录**实际执行量**（核对周计划是否跑偏） | STAGE-01-drills 热身处方 |
| 最差 | 次日热身的靶子；说不出「最差的一张」= 还没进入可修正的粒度 | [M03](../knowledge/M03-timed-sketch.md) §五 |
| 明天 | 盲区探测器——每月统计关键词，反复出现的下月专项 | — |

月底复盘时，这份日志 + 当月头尾同题材两张画 = 「进步」的可视化证据（出师考核第 5 项的原料）。
