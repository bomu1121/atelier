# practice/ · 练习存档

> 阶段手册和知识模块里反复引用的 `practice/年-月/log.md`、`practice/reference/` 就在这里。
> 这个目录的价值 = 你的**实验数据**：月度对比、出师考核、进步趋势、排障记录全靠它。

## 目录结构

```
practice/
├── README.md            # 本文件
├── LOG-TEMPLATE.md      # 每日三行日志模板（复制到当月 log.md）
├── reference/           # 临摹/参考素材（版权规则见 M05）
└── 2026-10/             # 「年-月」：每月一个文件夹
    ├── log.md           # 当月每日三行日志
    ├── 10-14-lines-01.png    # 练习图：日期-主题-序号
    ├── 10-14-copy-01.png     # 临摹图
    └── 10-14-copy-01-overlay.png  # 该临摹的叠图对比（成对存）
```

## 命名与配套约定

- 练习图：`日期-主题-序号`，如 `10-14-lines-01.png`。
- **临摹必配叠图**：临摹图 + 叠图对比**成对**存，叠图文件名加 `-overlay`（操作见 [M04](../knowledge/M04-overlay-compare.md)）。
- 主题词固定这套（可选，但固定了日后好筛选）：`lines`（排线直线）/ `ellipse`（椭圆）/ `copy`（临摹）/ `sketch`（速写）/ `free`（自由画）/ `study`（识势描线，M06）。

## 每日日志（3 行，收笔前写，1 分钟内）

建立当月 `log.md` 时从 [LOG-TEMPLATE.md](./LOG-TEMPLATE.md) 复制。**每月 1 号**翻一遍上月 log：统计「明天：」栏里反复出现的关键词——出现 3 次以上就是**系统性盲区**，下月专项打它。

## ⚠️ 隐私提醒（先说清）

**本仓库是 GitHub 公开仓库**（2026-10-10 经 GitHub API 确认 `"private": false`），所以：

- **不要**放本人照片、证件、工作敏感内容；
- 拿自己的照片当练习素材 → 进 `reference/` 前先自问是否愿意公开；
- 如果整个 practice/ 都不想进公开仓库：仓库根建 `.gitignore` 写入 `/practice/`（代价：失去 GitHub 备份，需本地自行备份）。

（一个反向的考虑：阶段 6 的曝光目标本来就需要公开练习成果——公开是特性不是 bug。这条提醒只保证你**知情**后再选。）
